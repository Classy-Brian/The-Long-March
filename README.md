# The Long March

Filipino Horror Game Jam 2026 entry: A survival decision game set during the Bataan Death March (April 1942), Oregon Trail–inspired, built in Godot 4.

## Structure
- `scenes/` — Godot scenes
- `scripts/` — GDScript sources
- `assets/` — art, audio, fonts (mostly placeholders for now)
- `Knowledge/` — design docs and project knowledge-transfer notes
