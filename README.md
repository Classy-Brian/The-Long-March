# The Long March

Filipino Horror Game Jam 2026 entry — a survival decision game set during the Bataan Death March (April 1942), Oregon Trail–inspired, built in Godot 4.

This is a real historical atrocity, not invented horror. See `Knowledge/bataan-march-gamejam-project-summary.md` and `Knowledge/game-design-one-pager.md` for full design context, decisions, and open questions — read those first if you're picking this project up.

## Status
Early scaffolding: parallax background structure, party/stat data model, and a first-pass typing-input ("Relentless Pace") node. Gameplay content (decision events, tuning, art) not yet built.

## Requirements
- Godot 4.x

## Structure
- `scenes/` — Godot scenes
- `scripts/` — GDScript sources
- `assets/` — art, audio, fonts (mostly placeholders for now)
- `Knowledge/` — design docs and project knowledge-transfer notes
